# **App Name**: ResumeRefine

## Core Features:

- Intelligent File Ingestion: Drag-and-drop interface to upload PDF and DOCX resumes with automatic text extraction and structural parsing.
- AI Match Gap Tool: A generative AI tool that identifies missing keywords and specific skill gaps by analyzing the resume against the target job description.
- Dynamic ATS Scoring: Visual 0-100 compatibility score generated through an analysis of keyword density, section formatting, and contact completeness.
- Keyword Optimizer: Interactive display highlighting matched skills in green and missing critical terms in red to guide resume editing.
- AI Content Improver Tool: A tool that uses reasoning to suggest specific bullet point revisions or additional experience highlights based on the job role requirements.
- Dual-Pane Analytics Dashboard: Side-by-side workspace featuring a resume preview on the left and a detailed analysis panel with insights on the right.
- Optimization Report Export: Functionality to generate and download a summarized PDF report of the findings and suggested improvements.

## Style Guidelines:

- Primary color is a refined Ultramarine Blue (#2D50E6) signifying reliability and tech-savviness; background is a clean Ice Blue (#F5F6FA); accent is a Cyan (#12A1DE) to differentiate between match types.
- Headline font is 'Space Grotesk' for its tech-forward, precise feel. Body text uses 'Inter' for a clean, machined, and neutral readability.
- Crisp, thin-stroke linear icons to maintain a professional, minimalist aesthetic suitable for executive tools.
- A highly functional split-view dashboard focusing on content comparison with collapsible utility drawers.
- Staggered entrance animations for report sections and smooth progress-fill transitions for the ATS score radial gauge.
