
AI Resume Analyzer + ATS Score Checker is a modern web application designed to help job seekers improve their resumes and increase their chances of getting shortlisted by Applicant Tracking Systems (ATS). The platform allows users to upload their resumes in PDF or DOCX format and receive an instant ATS score along with detailed feedback and improvement suggestions.

The system analyzes resume content using AI-based keyword matching, formatting checks, skill detection, and job-role relevance analysis. It compares the resume against industry standards and identifies missing keywords, weak sections, grammar issues, and formatting problems that may reduce ATS compatibility.

The application provides features such as:

ATS score calculation
Resume keyword analysis
Skills extraction
Job description matching
Resume improvement suggestions
Section-wise feedback
Modern and responsive dashboard UI
PDF/DOCX resume upload support

The frontend is built using React.js, HTML, and CSS to provide a clean and responsive user experience, while the backend is developed using Node.js for resume processing and analysis.

This project is useful for students, freshers, and professionals who want to optimize their resumes for better job opportunities and improve their chances of passing ATS screening systems used by companies.
